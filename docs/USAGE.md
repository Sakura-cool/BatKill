# BatKill 使用说明书（v0.2.6）

macOS 菜单栏工具：电池供电时自动停止指定软件省电，接入交流电自动恢复；附带实时温度监控与风扇控制。

## 一、安装

### 1. 下载

从 GitHub Releases 下载对应你 Mac 架构的安装包：

| 你的 Mac | 下载 |
|---------|------|
| Apple Silicon（M1/M2/M3/M4） | `BatKill-arm64.dmg` |
| Intel | `BatKill-x86_64.dmg` |

> 自 v0.2.3 起仅发布 `.dmg`，不再提供 `.zip`。

### 2. 安装

- **DMG**：双击挂载 → 把 `BatKill.app` 拖入「应用程序」→ 首次打开右键「打开」（未公证应用提示）

### 3. 启动

点击菜单栏出现的**电池图标**。首次启动会请求通知权限（用于省电/恢复提示）。

## 二、核心功能

### 1. 电池省电（自动停止指定软件）

1. 点击菜单栏电池图标 → **设置**
2. 勾选需要在**电池供电时自动停止**的软件
3. 点击「已选」查看/调整已选软件，可为每个软件设置**暂停方式**（见下方）
4. 拔掉电源线 → 30 秒后勾选的软件按各自**暂停方式**处理
5. 插回电源 → 被停止/挂起的软件**自动恢复**

> 快速插拔电源时自动合并，仅按最终状态操作。

#### 暂停方式（每个软件独立设置，v0.2.4）

在「已选」弹窗中，每个软件行可选三种暂停方式：

| 方式 | 行为 | 接电恢复 | 说明 |
|------|------|---------|------|
| **挂起** | `SIGSTOP` 冻结进程（原地保留） | `SIGCONT` 精确解冻 | 内存与状态 100% 保留；占内存、省电较弱 |
| **优雅退出**（默认） | 优雅退出 + 更长等待让软件落盘状态 | 重新启动，软件自恢复 | 依赖软件自身自动保存/断点续跑 |
| **强制退出** | 既有升级链（最省电兜底） | 重新启动 | 不保留状态 |

- 被挂起软件在列表显示「已挂起」黄色徽标；待恢复列表区分「待解冻」与「待重启」。
- 系统核心组件（Dock/Finder/WindowServer 等）不会出现在可管理列表，避免误操作影响系统。

### 2. 恢复与启动约束（v0.2.6）

接电恢复默认**依次有序**进行，并受电量与 CPU 占用约束：

#### 依次恢复（默认）

- 每段时间**仅恢复一个软件**，恢复完一个再恢复下一个，**不批量**（避免瞬间拉起多个软件造成卡顿）。
- 恢复间隔由**当前 CPU 占用**决定：空闲（<25%）约 2 秒/个，繁忙（≥75%）约 10 秒/个（中间档 4-6 秒）。
- 恢复进度显示「已恢复 x/N · 下一个：xxx · 间隔 Ns」。

#### 手动恢复双按钮（设置页底部）

| 按钮 | 行为 |
|------|------|
| **依次恢复** | 按待恢复列表顺序逐个恢复（同自动逻辑） |
| **批量快速恢复** | 一次性恢复全部（无间隔，可能短暂卡顿，执行前确认） |

#### 低电量门控

- 接电且电量 **<20%** → **延缓自动恢复**（待恢复列表保留，界面提示「电量不足，≥20% 后自动恢复」）。
- 电量充电至 **≥20%** 且仍在接电 → **自动开始恢复**。
- 门控**仅作用于自动恢复**；手动「依次恢复/批量快速恢复」不受影响。

#### 状态感知通知（v0.2.6）

电源/恢复状态变换时，通知会告知**当前处理状态**，而非笼统汇总：

- **电池切换（终止）**：按暂停方式分组通知——「已挂起：xxx / 已优雅退出：xxx / 已强制退出：xxx」
- **接电恢复**：区分「依次恢复中：已恢复 x/N」与「批量恢复完成：已恢复 N 个」
- **低电量门控**：生效「电量不足，恢复延缓（<20%）」/ 解除「电量充足，开始恢复」

#### 异常事件处理（v0.2.6）

| 异常 | BatKill 处理 |
|------|-------------|
| 恢复中点了「停止选中」或拔电源 | 恢复序列**自动取消**（未恢复项保留待恢复），随后执行终止；不并发 |
| 电源接触不良（10 秒内反复切换 ≥3 次） | 提醒「电源接触不良」+ **选择**：继续忽略异常继续恢复 / 暂停恢复 / 停止 |
| 恢复后电量下降 | 提醒「电源不足」，暂停恢复状态 |
| 电量快速下降（>5%/10 秒） | 提醒「消耗过大，建议处理」 |
| 电量 <20% | **自动帮用户处理**（暂停自动恢复） |
| 手动启动恢复 | 表示已知风险，忽略上述自动处理 |

### 3. 硬件监控（温度 + 风扇）

点击菜单栏**温度图标**打开硬件监控窗口：

- **温度**：各核心实时温度（P-Core/E-Core）
- **风扇**：每把风扇的转速、模式切换、转速设定

### 4. 风扇控制（三种模式）

每把风扇有三个模式，切换时**立即生效**：

| 模式 | 行为 | 状态徽标 |
|------|------|---------|
| **自动** | 交还系统自动控制 | `↩ 已恢复自动` |
| **定速** | 固定转速（拖动滑块设定，0.1s 后生效） | `✓ 已生效` / `⏳ 生效中` |
| **调速** | 按温度-转速曲线自动调速 | `✓ 已生效` / `⏳ 生效中` |

**首次使用风扇控制**：点击「启用风扇控制」→ 输入一次管理员密码 → 安装 `batkill-fan` 提权工具（之后零弹窗）。

#### 定速模式
- 拖动转速滑块 → 0.1 秒后写入生效
- 模式行显示设定目标与实际转速收敛状态

#### 调速模式
- 曲线图：X 轴温度、Y 轴转速
- 点击曲线节点可输入转速，拖拽节点快速调整
- 红色竖线 = 当前温度，红色横线 = 当前转速
- 调整节点后 0.1 秒生效

### 5. 风扇预设

- **保存当前**：把当前各风扇的模式/转速保存为预设
- **应用预设**：一键切到预设配置（含定速/调速子模式记忆）
- **删除预设**：右键或选择删除

### 6. 温度阈值保护

- 设置 CPU 温度阈值（60-120°C）
- 超阈值 → 自动交还系统控制（过温守护）
- 降温后恢复用户设置

## 三、常见问题

| 问题 | 解决 |
|------|------|
| 风扇控制灰蒙蒙 + 提示启用 | 点「启用风扇控制」并输入管理员密码（一次性）|
| 风扇转速不生效 | 确认已启用风扇控制；调速需先切到手动模式 |
| 软件被停止后不恢复 | 确认接入交流电；检查电量是否 ≥20%（<20% 会延缓自动恢复，可手动「依次恢复/批量快速恢复」）；若提示「电源接触不良」按对话框选择处理 |
| 恢复很慢 | 属正常（依次恢复 + CPU 占用感知间隔），高 CPU 占用时间隔延长 |
| 温度不显示 | 某些 Mac 型号传感器键不同，属正常范围差异 |

## 四、卸载

1. 删除 `BatKill.app`
2. （可选）移除风扇控制特权：
   ```bash
   sudo rm -f /usr/local/BatKill/batkill-fan /etc/sudoers.d/batkill-fan
   ```

## 五、更新

- 自动检查：启动后检测 GitHub 新版本，有更新时提示
- 手动：点击设置页/标题栏的更新按钮
- 下载后按提示安装重启

## 六、命令行诊断（高级）

```bash
# 读取风扇 0 当前转速
/usr/local/BatKill/batkill-fan --get-fan 0

# 风扇写通道自检（需已启用风扇控制）
bash Tests/integration/fan_channel_test.sh
```
