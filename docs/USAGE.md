# BatKill 使用说明书（v0.1.9）

macOS 菜单栏工具：电池供电时自动停止指定软件省电，接入交流电自动恢复；附带实时温度监控与风扇控制。

## 一、安装

### 1. 下载

从 GitHub Releases 下载对应你 Mac 架构的安装包：

| 你的 Mac | 下载 |
|---------|------|
| Apple Silicon（M1/M2/M3/M4） | `BatKill-arm64.dmg` 或 `.zip` |
| Intel | `BatKill-x86_64.dmg` 或 `.zip` |

### 2. 安装

- **DMG**：双击挂载 → 把 `BatKill.app` 拖入「应用程序」→ 首次打开右键「打开」（未公证应用提示）
- **ZIP**：解压 → 把 `BatKill.app` 拖入「应用程序」

### 3. 启动

点击菜单栏出现的**电池图标**。首次启动会请求通知权限（用于省电/恢复提示）。

## 二、核心功能

### 1. 电池省电（自动停止指定软件）

1. 点击菜单栏电池图标 → **设置**
2. 勾选需要在**电池供电时自动停止**的软件
3. 拔掉电源线 → 30 秒后勾选的软件自动关闭
4. 插回电源 → 被停止的软件自动恢复

> 快速插拔电源时自动合并，仅按最终状态操作。

### 2. 硬件监控（温度 + 风扇）

点击菜单栏**温度图标**打开硬件监控窗口：

- **温度**：各核心实时温度（P-Core/E-Core）
- **风扇**：每把风扇的转速、模式切换、转速设定

### 3. 风扇控制（三种模式）

每把风扇有三个模式，切换时**立即生效**：

| 模式 | 行为 | 状态徽标 |
|------|------|---------|
| **自动** | 交还系统自动控制 | `↩ 已恢复自动` |
| **定速** | 固定转速（拖动滑块设定，0.1s 后生效） | `✓ 已生效` / `⏳ 生效中` |
| **调速** | 按温度-转速曲线自动调速 | `✓ 已生效` / `⏳ 生效中` |

**首次使用风扇控制**：点击「启用风扇控制」→ 输入一次管理员密码 → 安装 `batkill-fan` 提权工具（之后零弹窗）。

#### 定速模式
- 拖动转速滑块 → 0.1 秒后写入生效
- 模式行显示设定目标与实际转速收敛状态

#### 调速模式
- 曲线图：X 轴温度、Y 轴转速
- 点击曲线节点可输入转速，拖拽节点快速调整
- 红色竖线 = 当前温度，红色横线 = 当前转速
- 调整节点后 0.1 秒生效

### 4. 风扇预设

- **保存当前**：把当前各风扇的模式/转速保存为预设
- **应用预设**：一键切到预设配置（含定速/调速子模式记忆）
- **删除预设**：右键或选择删除

### 5. 温度阈值保护

- 设置 CPU 温度阈值（60-120°C）
- 超阈值 → 自动交还系统控制（过温守护）
- 降温后恢复用户设置

## 三、常见问题

| 问题 | 解决 |
|------|------|
| 风扇控制灰蒙蒙 + 提示启用 | 点「启用风扇控制」并输入管理员密码（一次性）|
| 风扇转速不生效 | 确认已启用风扇控制；调速需先切到手动模式 |
| 软件被停止后不恢复 | 确认接入交流电；检查「设置」中该软件仍勾选 |
| 温度不显示 | 某些 Mac 型号传感器键不同，属正常范围差异 |

## 四、卸载

1. 删除 `BatKill.app`
2. （可选）移除风扇控制特权：
   ```bash
   sudo rm -f /usr/local/BatKill/batkill-fan /etc/sudoers.d/batkill-fan
   ```

## 五、更新

- 自动检查：启动后检测 GitHub 新版本，有更新时提示
- 手动：点击温度窗口标题栏刷新按钮旁的更新按钮
- 下载后按提示安装重启

## 六、命令行诊断（高级）

```bash
# 读取风扇 0 当前转速
/usr/local/BatKill/batkill-fan --get-fan 0

# 风扇写通道自检（需已启用风扇控制）
bash Tests/integration/fan_channel_test.sh
```
